# Jeremiah Akindureni — Full-Stack Developer & Aspiring ML Engineer Portfolio

A modern, high-performance, and accessible developer portfolio website built for **Jeremiah Akindureni**, designed for networking, personal branding, and showcasing real-world shipped applications.

Inspired by the clean, minimalist aesthetic of the "Developer X" portfolio architecture — featuring deep slate dark mode, vivid Royal Electric Blue accents, crisp typography, and an asymmetric 3-column desktop hero layout.

---

## 🌟 Key Features

- **Asymmetric 3-Column Hero**: Faithful implementation of the reference layout with developer name, tagline, intro, interactive down-action button, Jeremiah's portrait, and quick About/Work/Socials cards.
- **Production Projects Grid**:
  - **Rent Tracker**: Full-Stack Property Management SaaS (Next.js 16, React 19, TypeScript, Tailwind CSS, Prisma, SQLite, HTTP-only cookie auth, Framer Motion).
  - **PropNest**: Full-Stack Property Marketplace connecting Nigerian seekers with agents ([propnests.org](https://propnests.org)).
  - **SmartBite**: Smart Food Suggestion System with dietary and budget engines ([smaartbite.netlify.app](https://smaartbite.netlify.app)).
  - **CampusFund**: Student micro-crowdfunding platform with transparent bank transfers ([campusfund.netlify.app](https://campusfund.netlify.app)).
- **Interactive About & Timeline**: Detailed career narrative, current role as IT Manager at Lisa Technologies Ltd, B.Sc. Computer Science at LASUED, and categorized skills matrix.
- **ATS-Friendly Printable Resume**: Interactive `/resume` page with print styling and clean CV layout.
- **Dynamic Contact Hub**: One-click copy for email and phone, quick WhatsApp links, and an interactive contact form with real-time validation and feedback.
- **Lagos Local Time Ticker**: Real-time West Africa Time (`WAT` / `GMT+1`) clock in the footer.
- **Dark / Light Mode**: Seamless theme switching with dark mode as default matching Developer X.
- **Accessible & SEO Ready**: Semantic HTML, Open Graph tags, Twitter cards, and SVG favicon.

## 🛠️ Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **UI Library**: React 19
- **Language**: TypeScript

- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Theming**: next-themes
- **Effects**: canvas-confetti

## 🚀 Getting Started Locally

1. Clone or navigate to the repository directory:
```bash
cd "My Portfolio"
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build & Deployment

To generate an optimized static production build:
```bash
npm run build
```

To run the production server locally:
```bash
npm run start
```

### Deploying to Vercel
1. Push the code to a GitHub repository (e.g. `github.com/Jerrykay60/portfolio`).
2. Import the repository in [Vercel](https://vercel.com).
3. Vercel automatically detects Next.js — click **Deploy**.
